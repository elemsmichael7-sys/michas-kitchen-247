# Micha's Kitchen - Restaurant Website

A responsive website for a restaurant, built with HTML, CSS and JavaScript.

## Pages
- Home - Welcome, introduction, popular dishes
- About - History, mission, vision
- Services/Menu - Dine-in, Takeaway, Delivery + Full Menu
- Contact - Contact info + form with JavaScript validation

## Technologies Used
- HTML - Semantic elements, headings, lists, forms, images
- CSS - External stylesheet, Flexbox, Grid, Media Queries, Box Model
- JavaScript - Variables, functions, event handling, form validation, interactive button

## How to Run
1. Download this project
2. Open `index.html` in a browser
